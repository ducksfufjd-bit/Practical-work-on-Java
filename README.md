# Практическая работа №1 — Матрицы комплексных чисел

## Описание проекта

Консольное приложение на языке Java для выполнения математических операций над матрицами комплексных чисел.

Программа позволяет создавать матрицы, вводить их элементы с клавиатуры и выполнять выбранные пользователем операции.

## Возможности программы

- Сложение двух матриц
- Умножение двух матриц
- Деление матриц через обратную матрицу
- Транспонирование матрицы
- Вычисление определителя матрицы
- Проверка корректности размеров матриц
- Обработка ошибок ввода

## Структура проекта

Проект состоит из трёх классов:

- **Complex.java** — класс комплексных чисел. Реализует сложение, вычитание, умножение и деление комплексных чисел.
- **Matrix.java** — класс матриц. Содержит методы для выполнения операций над матрицами комплексных чисел.
- **Main.java** — основной класс программы. Реализует консольное меню и ввод данных пользователем.

## Используемые технологии

- Java 21
- IntelliJ IDEA

## Работа с программой

После запуска пользователь выбирает операцию из меню:

1. Сложение матриц
2. Умножение матриц
3. Транспонирование матрицы
4. Вычисление определителя
5. Деление матриц
0. Выход

Далее необходимо указать размеры матрицы и ввести действительную и мнимую части каждого элемента.

Программа выполняет выбранную операцию и выводит результат в консоль.

## Особенности реализации

- Сложение возможно только для матриц одинакового размера.
- Умножение возможно, если количество столбцов первой матрицы совпадает с количеством строк второй.
- Определитель вычисляется только для квадратных матриц.
- Деление реализовано через умножение на обратную матрицу.
- Вторая матрица при делении должна быть квадратной и обратимой.
- При некорректных размерах или невозможности выполнения операции выводится сообщение об ошибке.
